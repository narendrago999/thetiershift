PLATFORM BUILDING BLOCKS

Design for operability, not just data movement

INGESTION

Incremental by design

Use Auto Loader for scalable file discovery, CDC where source change capture is available, and Structured Streaming for event-driven use cases. Make retries idempotent.

STORAGE & PROCESSING

Delta Lake as the table layer

Use ACID transactions, schema enforcement and evolution deliberately. Optimise file sizes, clustering and retention based on observed access patterns.

GOVERNANCE

Unity Catalog controls

Centralise discovery, privileges, lineage and governed sharing. Use service principals and least-privilege grants for production workloads.

WORKLOAD DESIGN

Separate engineering concerns from consumption

Data engineering operations

  • Orchestrate dependencies with Workflows or Lakeflow.
  • Parameterise environments and externalise secrets.
  • Capture expectations, rejected rows and quality metrics.
  • Monitor freshness, job duration, retries and spend.

Governed data consumption

  • Publish stable, documented Gold data products.
  • Apply row/column access controls where required.
  • Use SQL warehouses sized to workload demand.
  • Track model and feature lineage for ML and AI use.
PRODUCTION READINESS

Architecture decisions that prevent expensive rework

SECURITY

Identity and network boundaries

Define workspace isolation, private connectivity requirements, secret management and service identity before connecting production sources.

RELIABILITY

Replay and recovery

Set checkpoint, schema evolution, backfill and late-arriving data policies. Ensure a failed downstream task does not silently corrupt published data.

COST & PERFORMANCE

Measure before tuning

Right-size compute, use workload-specific clusters or warehouses, review query profiles and track storage and job cost by domain.

COMMON QUESTIONS

Databricks lakehouse FAQ

Is a lakehouse the same as a medallion architecture?

No. A lakehouse describes the platform pattern combining data lake flexibility with warehouse capabilities. Bronze, Silver and Gold are a common logical organisation pattern implemented on that platform.

When should we use Auto Loader?

Auto Loader is useful for incrementally discovering and ingesting new files from supported cloud storage locations. For database CDC or event streaming, use the appropriate source-specific ingestion pattern.

Is Unity Catalog required for governance?

For modern Databricks deployments, Unity Catalog is the recommended central governance layer for data and AI assets. Plan metastore, catalog, schema, ownership and access boundaries early.

Can Databricks support both BI and machine learning?

Yes. Curated Delta tables can serve SQL and BI workloads while the same governed foundation supports feature engineering, model training, batch inference and retrieval systems.
