DESIGN THE LAYERS

What belongs in each layer?

BRONZE · TRACEABILITY

Retain what arrived

Store source-aligned records with ingestion timestamps, batch identifiers and source references. Prefer append-oriented patterns where replay and auditability matter.

SILVER · TRUST

Make data dependable

Standardise schemas, parse dates and amounts, handle nulls, remove duplicates, validate relationships and quarantine records that fail critical rules.

GOLD · BUSINESS VALUE

Model for decisions

Publish reusable facts, dimensions and aggregates aligned to business processes, with clear ownership, definitions and refresh expectations.

IMPLEMENTATION CHECKLIST

Decisions to settle before production

Ingestion strategyChoose batch, incremental, CDC or streaming per source; define watermark and replay behaviour.
Data contractsAgree schema ownership, change handling, required fields and compatibility rules with source teams.
Quality gatesSet row-count, uniqueness, referential, freshness and financial reconciliation checks.
Security boundariesSeparate workspaces and environments; apply least privilege and sensitive-data controls.
Operational readinessTrack pipeline duration, failures, freshness, cost and SLA breaches with actionable alerts.
Release managementUse version control, deployment pipelines and environment-specific configuration for repeatable releases.
COMMON QUESTIONS

Microsoft Fabric medallion architecture FAQ

Do Bronze, Silver and Gold have to be separate lakehouses?

No. They can be schemas or other logical boundaries within a lakehouse, or separate lakehouses/workspaces. Choose the boundary based on security, ownership, lifecycle, performance and operational needs.

Should transformations use notebooks or Dataflow Gen2?

Use the tool that fits the workload and team. Dataflow Gen2 can suit low-code ingestion and transformation; notebooks are useful for code-driven Spark transformations, reusable logic and complex processing. Many platforms use both.

How should Power BI consume Gold data?

Expose curated models through a governed semantic model. Direct Lake can reduce data duplication for suitable Fabric workloads, while Import or DirectQuery may fit other constraints.

How do we stop bad source data reaching reports?

Implement explicit quality gates between layers, quarantine failed records, publish quality metrics and prevent Gold publication when critical checks fail.
