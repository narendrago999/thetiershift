Senior Software Engineer

We're looking for an experienced, hands-on engineer who can own complex software delivery, shape sound technical solutions and help our teams build secure, scalable products for real business needs.

EngineeringFull-time5–8 years preferredRemote / Hybrid discussion

Role overview

You will work across the full software lifecycle — understanding business requirements, designing architecture, building frontend and backend capabilities, integrating cloud and data services, and supporting production systems. You will provide technical direction while remaining comfortable writing and reviewing production code.

Roles and responsibilities

  • Lead design, development, testing and delivery of scalable web applications, platforms and software products.
  • Translate business requirements into technical designs, solution architecture, estimates and delivery plans.
  • Build responsive, accessible user interfaces using React / Next.js and TypeScript or comparable modern frameworks.
  • Design and develop backend services, REST APIs, integrations and event-driven components using Node.js, .NET, Java or equivalent technologies.
  • Design efficient data models and work confidently with SQL and NoSQL databases.
  • Apply secure coding practices, authentication and authorisation patterns, API security and data protection principles.
  • Build and operate cloud-based solutions on Azure, AWS or Google Cloud; use Docker and CI/CD pipelines for reliable releases.
  • Establish engineering standards for code quality, automated testing, observability, performance and maintainability.
  • Review code, mentor engineers, unblock teammates and encourage practical knowledge sharing.
  • Collaborate with product, design, data and client stakeholders; communicate trade-offs, risks and progress clearly.
  • Investigate production issues, perform root-cause analysis and drive sustainable fixes.
  • Evaluate new tools and AI-assisted development approaches where they improve delivery quality, security or productivity.

Required technical skills

  • 5+ years of professional software engineering experience, with evidence of independently delivering production systems.
  • Strong proficiency in JavaScript / TypeScript and a modern frontend framework such as React or Next.js.
  • Strong backend engineering experience with Node.js and a framework such as Express or NestJS; equivalent backend experience is welcome.
  • Solid understanding of REST API design, distributed systems fundamentals, asynchronous processing and integration patterns.
  • Practical SQL skills and experience with relational databases such as PostgreSQL, MySQL or SQL Server; familiarity with NoSQL is an advantage.
  • Experience with Git, pull requests, code reviews, automated testing and debugging.
  • Working knowledge of cloud services, deployment pipelines, Docker and production monitoring.
  • Understanding of application security, performance optimisation, accessibility and responsive design.

Good to have

  • Experience with Azure, AWS or GCP architecture and infrastructure as code such as Terraform or Bicep.
  • Exposure to Python, data engineering, analytics platforms or AI / LLM application integrations.
  • Experience with microservices, message queues, caching, Kubernetes or serverless architectures.
  • Experience working directly with clients, technical discovery, estimation and solution proposals.

What we're looking for

  • Strong ownership, structured problem-solving and sound engineering judgement.
  • Ability to balance delivery speed with quality, reliability and long-term maintainability.
  • Clear written and verbal communication, collaboration and a mentoring mindset.
  • Curiosity, adaptability and a commitment to continuous learning.

Education and experience

A bachelor's degree in Computer Science, Information Technology or a related discipline is preferred, or equivalent practical experience. We value demonstrable engineering capability and the quality of systems you've delivered.
