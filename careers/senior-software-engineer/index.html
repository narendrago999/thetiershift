Senior Software Engineer

Own complex software delivery, shape technical solutions and help build secure, scalable products for real business needs.

← All open positions

About the opportunity

You will work across the full software lifecycle — understanding business requirements, designing architecture, building frontend and backend capabilities, integrating cloud and data services, and supporting production systems. You will provide technical direction while remaining comfortable writing and reviewing production code.

Full-time5+ yearsRemote / Hybrid discussionIndia

Responsibilities

  • Lead design, development, testing and delivery of scalable web applications, platforms and software products.
  • Translate business requirements into technical designs, solution architecture, estimates and delivery plans.
  • Build responsive user interfaces using React / Next.js and TypeScript.
  • Design backend services, REST APIs and integrations using Node.js, .NET, Java or equivalent technologies.
  • Design efficient data models and work with SQL and NoSQL databases.
  • Apply secure coding, authentication, API security and data protection principles.
  • Build and operate cloud solutions on Azure, AWS or Google Cloud; use Docker and CI/CD.
  • Establish standards for code quality, automated testing, observability, performance and maintainability.
  • Review code, mentor engineers and encourage knowledge sharing.
  • Collaborate with product, design, data and client stakeholders; communicate trade-offs and progress.
  • Investigate production issues, perform root-cause analysis and drive sustainable fixes.

Required technical skills

  • 5+ years of professional software engineering experience delivering production systems.
  • Strong JavaScript / TypeScript and a modern frontend framework such as React or Next.js.
  • Strong backend experience with Node.js and Express / NestJS or equivalent frameworks.
  • Solid understanding of REST API design, distributed systems, asynchronous processing and integration patterns.
  • Practical SQL skills and experience with PostgreSQL, MySQL or SQL Server; NoSQL is an advantage.
  • Experience with Git, pull requests, code reviews, automated testing and debugging.
  • Working knowledge of cloud services, deployment pipelines, Docker and production monitoring.
  • Understanding of application security, performance, accessibility and responsive design.

Good to have

  • Azure, AWS or GCP architecture and infrastructure as code such as Terraform or Bicep.
  • Exposure to Python, data engineering, analytics or AI / LLM integrations.
  • Microservices, message queues, caching, Kubernetes or serverless architectures.
  • Client-facing technical discovery, estimation and solution proposals.

What we're looking for

  • Strong ownership, structured problem-solving and sound engineering judgement.
  • Ability to balance delivery speed with quality, reliability and maintainability.
  • Clear communication, collaboration and a mentoring mindset.

A bachelor's degree in Computer Science, IT or a related discipline is preferred, or equivalent practical experience.
